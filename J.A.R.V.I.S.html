Settings

Web-app limits: it only works while this page is open with the screen on, and Android may pause the mic if you switch apps or lock the phone. Clap detection uses a second mic stream, which some phones refuse while speech recognition runs; if it never triggers, rely on the wake word. Headset detection depends on what Chrome exposes; if Jarvis stays silent with Privacy mode on, switch it off. A browser cannot toggle Wi-Fi, Bluetooth, data, DND or brightness by itself; Jarvis opens the right settings screen and you flip the switch. Full background control needs a native Android app.

Android only lets native apps be the "Default digital assistant", and a web page cannot register itself as one, so it will never appear in that list or answer to the system "Hey Google" trigger. These are the closest options:

To make Jarvis feel like an app: host this file on any https page (GitHub Pages or Netlify, free), open it in Chrome, then Menu, Add to Home screen or Install app. It then opens full screen from its own icon.
